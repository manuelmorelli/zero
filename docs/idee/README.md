# Cartella idee

Qui salviamo le idee che non sono ancora nel lavoro di oggi, così non si perdono. Ogni idea ha uno stato e viene aggiornata man mano che cambia.

## Stati

- **Da fare**: idea decisa, da realizzare.
- **Da studiare**: idea da approfondire prima di decidere.
- **Già fatta**: realizzata, la si toglie dalla lista.
- **Scartata**: decisa di non farla, con il motivo scritto accanto.

Le idee già fatte o scartate si tolgono dai file, così ogni file mostra solo quello che resta da fare.
